# Home 拾光

与 Home 共用 Three.js renderer。保留原夜空 / 白天背景；中心几何体是夜间超立方体、日间莫比乌斯带。拾光中几何体不响应点击沉浸，漫游中保持原交互。

卡片由 `src/content/home-cards.json` 驱动，维护方法见 `src/content/HOME-CARDS.md`；支持诗文纸卡、图片相框和长诗分页。`/playground/home-cards` 使用相同画布渲染器预览全部内容。

`motion.ts` 保留已确认的 2.5 倍飞行速度、v2 弹簧和 0.135 拖拽角增益。文字卡与图片卡交替出现；每隔随机 3～6 次内容掉落插入一颗四角立体星星，合计最多两个活动物体。仅按需解码图片、生成活动卡片的 CanvasTexture；图片离场后释放解码图像、纹理和几何体。失效图片单独跳过。只释放模块自己创建的材质、几何体与纹理，不释放共享 renderer。

`src/composables/star-clock.ts` 与共享的 `star-clusters.ts` 将约 24% 的原有星星归拢为十二条钟面方向的射线，沿纵深向外流动，并根据指针产生轻微视差。进入 / 退出约 1.25 秒；退出后恢复原星空。星星仍由原来的单个 Points 绘制。减少动态效果偏好下使用静态排列。

桌面默认拾光，手机默认漫游，两端右下角可切换。会话中手动选择优先于窗口宽度。

首页星线参数在 `src/content/home-stars.json`：每线 8 簇、宽度 100%、聚簇 5%、弯曲 100%、流速 25%、视差 100%。首页与 Playground 使用相同的渲染逻辑；后者可通过“首页选定”恢复这组参数。
