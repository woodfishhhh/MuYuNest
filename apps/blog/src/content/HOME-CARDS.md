# 拾光卡片

编辑同目录的 `home-cards.json` 即可增删改。`cards` 中每个对象是一首诗或一张照片，`id` 必须唯一。同一天可以有多张卡片。

当前诗卡以 JSON 配置为准，无标题的使用“无题”，正文按输入的换行保留。10.17 的 `14.jpg` 尚未提供，已预留 `enabled: false` 的图片条目。

## 文字卡片

```json
{
  "id": "poem-2024-10-15",
  "type": "text",
  "title": "无题",
  "date": "2024-10-15",
  "text": [
    "我抚苍穹触天边，阅尽宇宙盲文篇。",
    "以天作琴云作弦，有象无形美如胭。"
  ]
}
```

标题显示为“无题 - 2024.10.15”，下方是正文。省略 `title` 也会使用“无题”，`date` 可省略。`text` 可以逐行写成数组，也可以是含 `\n` 换行的字符串；空字符串行保留段间空行。长行自动换行，超过一张卡片的长诗自动分页，并在底部标页码，全文不会截断。

可选 `paper` 为 `warm`（默认）、`white`、`dark`；`align` 为 `center`（默认）或 `left`。

## 图片相框

```json
{
  "id": "photo-2024-10-17",
  "type": "image",
  "title": "无题",
  "date": "2024-10-17",
  "src": "local:14.jpg",
  "alt": "十月的一张照片",
  "description": "我的镜头下1",
  "frame": "white",
  "fit": "contain"
}
```

图片文件放在 `apps/blog/src/assets/home-flight/photos/`，通过 `local:文件名` 引用；也可以直接把 `src` 换成上传图床后得到的 HTTPS 图片地址，或已有的站内 `/asset/文件名` 地址。外部图床必须允许跨域读取图片（CORS），否则该图片跳过，不影响诗卡。

相框保留完整图片与边框，可选 `description` 添加下方描述，例如“我的镜头下1”或“love CS”；旧字段 `caption` 仍兼容，`description` 优先。`title` 和 `date` 用于预览目录，不会强行印到相框上。`frame` 支持 `white`、`black`、`wood`；`fit: contain` 保留整张图片，`cover` 填满裁切。默认跟随图片比例，`aspectRatio` 可以固定画框宽高比（0.4～2.5，例如 `1` 为正方形）。

## 日常维护

- 新增：在 `cards` 数组中复制一项，改唯一 `id` 和内容。
- 修改：直接改标题、日期、正文或图片地址。
- 暂时隐藏：加 `"enabled": false`。重新启用改为 `true` 或删除该字段。
- 删除：移除整个对象，注意 JSON 逗号。
- 查看全部排版：打开 `/playground/home-cards`。首页按文字卡 → 图片卡交替播放；两类内容各自按 JSON 列表顺序循环，播完一轮才从头开始，长诗按分页顺序出现。每隔随机 3～6 次内容掉落插入一颗四角立体星星，星星不打断文字/图片交替顺序。卡片和星星合计同屏最多两个。

JSON 关联了 `home-cards.schema.json`，支持的编辑器会提示字段和格式错误。开发预览会热更新；生产站点修改配置或新增本地图片后需要重新构建部署。修改这些卡片不需要运行 Markdown 文章内容生成器。

卡片会跟随网站昼夜主题：夜间采用深色纸面、深色相框与浅灰文字，并轻微降低照片显示亮度；白天采用柔和浅色。原始照片文件不变。排版预览页也可以切换昼夜检查。

首页照片相框与诗卡使用相同的默认宽度和厚度，高度跟随照片比例；抓住后仍可用滚轮调整大小。九宫格照片独立编号为“我的镜头下1”至“我的镜头下9”，其余照片直接使用名称。

首页滚轮不再跳转 Author。抓住卡片时，滚轮向上放大、向下缩小，范围为当前卡片基础大小的 0.5～3 倍；松手消散后，下次出场恢复基础大小。

当前收录的 16 张图片已优化为 WebP，最长边不超过 1600px；“love CS”截图使用无损 WebP。原始上传文件保持原样。首页按需解码当前要出现的图片，离场后释放图片和纹理。WebP 不进入离线预缓存，实际访问后才缓存，避免首次打开网站就下载整个相册。
