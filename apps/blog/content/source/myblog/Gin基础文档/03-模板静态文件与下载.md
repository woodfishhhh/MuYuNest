# Gin 基础（03）：HTML 模板、静态文件与下载

HTML 页面、静态资源和下载文件都通过 HTTP 返回字节，但各自的组织方式不同。模板先把数据填进 HTML；静态路由把 URL 映射到磁盘文件；下载响应再用头部说明“把内容保存成附件”。

## 先把目录和 URL 分开

示例目录如下：

```text
gin-03-files/
├── main.go
├── templates/index.html
├── static/site.css
└── files/report.csv
```

`/assets/site.css` 是浏览器访问的 URL，`static/site.css` 是服务器上的文件路径。`r.Static("/assets", "static")` 把二者联系起来，并不要求两个名字相同。

使用 Go 1.25 或更高版本，新建独立目录。以下命令按 PowerShell 7 编写；Linux/macOS 请求示例中的 `curl.exe` 可换成 `curl`。

```powershell
mkdir gin-03-files
Set-Location gin-03-files
go mod init example.com/gin-03-files
go get github.com/gin-gonic/gin@v1.12.0
```

每个示例单独运行，避免多个 `main` 函数放进同一个包。

按目录结构创建文件。`main.go` 的完整内容是：

```go
package main

import (
	"log"
	"net/http"
	"path/filepath"

	"github.com/gin-gonic/gin"
)

func NewRouter(baseDir string) *gin.Engine {
	r := gin.New()
	r.Use(gin.Recovery())
	if err := r.SetTrustedProxies(nil); err != nil {
		panic(err)
	}
	r.LoadHTMLGlob(filepath.Join(baseDir, "templates", "*.html"))
	r.Static("/assets", filepath.Join(baseDir, "static"))
	r.GET("/", func(c *gin.Context) {
		c.HTML(http.StatusOK, "index.html", gin.H{
			"title": "Gin 文件示例", "name": c.DefaultQuery("name", "访客"),
		})
	})
	r.Match([]string{http.MethodGet, http.MethodPost}, "/download", func(c *gin.Context) {
		// 服务端选择固定文件，客户端只决定是否发起下载。
		c.Header("Content-Type", "text/csv; charset=utf-8")
		c.FileAttachment(filepath.Join(baseDir, "files", "report.csv"), "学习报告.csv")
	})
	return r
}

func main() {
	// 此程序从 03-files 目录运行，因此模板和文件路径以该目录为基准。
	if err := NewRouter(".").Run("127.0.0.1:8080"); err != nil {
		log.Fatal(err)
	}
}
```

`templates/index.html`：

```html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8">
  <title>{{.title}}</title>
  <link rel="stylesheet" href="/assets/site.css">
</head>
<body>
  <h1>你好，{{.name}}</h1>
  <a href="/download">下载学习报告</a>
</body>
</html>
```

`static/site.css`：

```css
body { max-width: 48rem; margin: 3rem auto; padding: 0 1rem; font-family: sans-serif; }
```

`files/report.csv`：

```csv
topic,status
gin,learning
```

## 模板为什么要先加载

`LoadHTMLGlob` 在启动阶段解析匹配到的模板；`c.HTML(200, "index.html", data)` 在请求阶段找到这个模板，再把 `data` 传进去。模板中的 `{{.title}}` 和 `{{.name}}` 对应传入映射的键。

只有几个固定模板时，可以改用 `LoadHTMLFiles` 明确列出文件。Glob 是文件匹配模式，不代表任意深度递归扫描。相对路径依据进程的工作目录解析，`go run` 所在目录不对时，即使源码旁边有模板也可能找不到。

Gin 使用 Go 的 `html/template`。普通字符串会按所处 HTML 上下文转义。访问 `/?name=%3Cscript%3Ealert(1)%3C%2Fscript%3E` 时，名字应当作为文本显示，而不是执行脚本。不要为了“保留 HTML”就把用户输入转成 `template.HTML`，那会改变转义边界。[Gin HTML 渲染](https://gin-gonic.com/en/docs/rendering/html-rendering/)

## 下载由响应头和浏览器交互共同决定

`c.FileAttachment` 接收服务器文件路径和展示给用户的下载名，设置附件响应头后发送文件。这里同时注册了 GET 和 POST，两种方法都能返回同一份 CSV。

```powershell
go run .
```

在另一个终端检查：

```powershell
curl.exe -i "http://127.0.0.1:8080/?name=Lin"
curl.exe -i "http://127.0.0.1:8080/assets/site.css"
curl.exe -i -X POST "http://127.0.0.1:8080/download"
curl.exe -o report.csv "http://127.0.0.1:8080/download"
```

下载响应是 `200`，包含 `Content-Disposition: attachment`，文件内容是前面给出的两行 CSV。非 ASCII 下载名会使用编码后的头部参数，检查时不应假定整个头部一定是 `filename=普通中文`。

浏览器直接点击链接通常发出 GET，这是链接的行为；后端通过 POST 返回文件同样可行。若通过 `fetch` 发出 POST，拿到响应后还要把 Blob 交给下载链接：

```javascript
async function downloadReport() {
  const response = await fetch('/download', { method: 'POST' });
  if (!response.ok) throw new Error(`下载失败：${response.status}`);
  const blob = await response.blob();
  const url = URL.createObjectURL(blob);
  const link = document.createElement('a');
  link.href = url;
  link.download = '学习报告.csv';
  document.body.appendChild(link);
  link.click();
  link.remove();
  setTimeout(() => URL.revokeObjectURL(url), 1000);
}
```

这段函数在同源页面中运行。跨域时，还要满足 CORS；如果 JavaScript 需要读取 `Content-Disposition` 等非简单响应头，服务端要相应暴露该头部。`application/octet-stream` 说明媒体类型，不能单独代替附件头或前端的下载动作。

## 文件路径的边界

不要把 `c.Query("path")` 直接传给 `c.File`。应该先用业务 ID 找到已经获准访问的文件，再选择磁盘路径。需要下载授权的文件也不应放进完全公开的静态目录。

`Static("/assets", ...)` 会占用 `/assets/*filepath` 路由空间，不能再用 `/assets/:id` 注册另一套参数路由。公共资源放 `/assets`，业务接口放 `/api`，路径关系会清楚很多。

临时签名下载地址适合对象存储、大文件或限时授权，但不是每个小文件下载的必选方案。普通附件接口、浏览器 Blob 和签名 URL 应根据文件大小及授权方式选择。

参考：[静态文件](https://gin-gonic.com/en/docs/rendering/serving-static-files/)、[FileAttachment](https://pkg.go.dev/github.com/gin-gonic/gin@v1.12.0#Context.FileAttachment)。
