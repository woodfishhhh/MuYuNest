# Gin 基础（03）：HTML 模板、静态文件与下载

HTML 页面、静态资源、下载文件，都是通过 HTTP 返回字节，只是组织方式不一样：

- 模板：先把数据填进 HTML。
- 静态路由：把 URL 映射到磁盘文件。
- 下载响应：用头部说明“把内容保存成附件”。

## 先把目录和 URL 分开

示例目录：

```text
gin-03-files/
├── main.go
├── templates/index.html
├── static/site.css
└── files/report.csv
```

`/assets/site.css` 是浏览器访问的 URL，`static/site.css` 是服务器上的文件路径。`r.Static("/assets", "static")` 把两者对应起来，两个名字不用一样。

用 Go 1.25 或更高版本，新建一个独立目录。下面的命令按 PowerShell 7 写；Linux/macOS 上把请求示例里的 `curl.exe` 换成 `curl`。

```powershell
mkdir gin-03-files
Set-Location gin-03-files
go mod init example.com/gin-03-files
go get github.com/gin-gonic/gin@v1.12.0
```

每个示例单独运行，别把多个 `main` 函数放进同一个包。

按目录结构建文件。`main.go` 完整内容：

```go
package main

import (
	"log"
	"net/http"
	"path/filepath"

	"github.com/gin-gonic/gin"
)

func NewRouter(baseDir string) *gin.Engine {
	r := gin.New()
	r.Use(gin.Recovery())
	if err := r.SetTrustedProxies(nil); err != nil {
		panic(err)
	}
	r.LoadHTMLGlob(filepath.Join(baseDir, "templates", "*.html"))
	r.Static("/assets", filepath.Join(baseDir, "static"))
	r.GET("/", func(c *gin.Context) {
		c.HTML(http.StatusOK, "index.html", gin.H{
			"title": "Gin 文件示例", "name": c.DefaultQuery("name", "访客"),
		})
	})
	r.Match([]string{http.MethodGet, http.MethodPost}, "/download", func(c *gin.Context) {
		// 服务端选择固定文件，客户端只决定是否发起下载。
		c.Header("Content-Type", "text/csv; charset=utf-8")
		c.FileAttachment(filepath.Join(baseDir, "files", "report.csv"), "学习报告.csv")
	})
	return r
}

func main() {
	// 此程序从 03-files 目录运行，因此模板和文件路径以该目录为基准。
	if err := NewRouter(".").Run("127.0.0.1:8080"); err != nil {
		log.Fatal(err)
	}
}
```

`templates/index.html`：

```html
<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8">
  <title>{{.title}}</title>
  <link rel="stylesheet" href="/assets/site.css">
</head>
<body>
  <h1>你好，{{.name}}</h1>
  <a href="/download">下载学习报告</a>
</body>
</html>
```

`static/site.css`：

```css
body { max-width: 48rem; margin: 3rem auto; padding: 0 1rem; font-family: sans-serif; }
```

`files/report.csv`：

```csv
topic,status
gin,learning
```

## 模板为什么要先加载

`LoadHTMLGlob` 在启动时解析匹配到的模板；`c.HTML(200, "index.html", data)` 在请求时找到这个模板，再把 `data` 传进去。模板里的 `{{.title}}` 和 `{{.name}}` 对应传入映射的键。

只有几个固定模板，可以改用 `LoadHTMLFiles` 把文件明确列出来。Glob 只是文件匹配模式，不会递归扫描任意深度。相对路径按进程的工作目录解析，`go run` 所在目录不对，源码旁边明明有模板也可能找不到。

Gin 用的是 Go 的 `html/template`，普通字符串会按所在的 HTML 上下文转义。访问 `/?name=%3Cscript%3Ealert(1)%3C%2Fscript%3E`，名字会当文本显示，脚本不会执行。别为了“保留 HTML”把用户输入转成 `template.HTML`，那样会绕过转义。[Gin HTML 渲染](https://gin-gonic.com/en/docs/rendering/html-rendering/)

## 下载由响应头和浏览器交互共同决定

`c.FileAttachment` 接收服务器文件路径和展示给用户的下载名，设好附件响应头再发送文件。这里 GET 和 POST 都注册了，两种方法返回同一份 CSV。

```powershell
go run .
```

另开一个终端检查：

```powershell
curl.exe -i "http://127.0.0.1:8080/?name=Lin"
curl.exe -i "http://127.0.0.1:8080/assets/site.css"
curl.exe -i -X POST "http://127.0.0.1:8080/download"
curl.exe -o report.csv "http://127.0.0.1:8080/download"
```

下载响应是 `200`，带 `Content-Disposition: attachment`，文件内容就是前面那两行 CSV。非 ASCII 下载名会用编码后的头部参数，检查时别假定整个头部一定是 `filename=普通中文`。

浏览器直接点链接一般发 GET，这是链接本身的行为；后端用 POST 返回文件也可以。用 `fetch` 发 POST 的话，拿到响应后还要把 Blob 交给下载链接：

```javascript
async function downloadReport() {
  const response = await fetch('/download', { method: 'POST' });
  if (!response.ok) throw new Error(`下载失败：${response.status}`);
  const blob = await response.blob();
  const url = URL.createObjectURL(blob);
  const link = document.createElement('a');
  link.href = url;
  link.download = '学习报告.csv';
  document.body.appendChild(link);
  link.click();
  link.remove();
  setTimeout(() => URL.revokeObjectURL(url), 1000);
}
```

这段函数跑在同源页面里。跨域时还要满足 CORS；JavaScript 要读 `Content-Disposition` 这类非简单响应头，服务端得把这个头部暴露出来。`application/octet-stream` 只说明媒体类型，单靠它代替不了附件头，也代替不了前端的下载动作。

## 文件路径的边界

别把 `c.Query("path")` 直接传给 `c.File`。先用业务 ID 找到已获准访问的文件，再确定磁盘路径。需要授权才能下载的文件，也别放进完全公开的静态目录。

`Static("/assets", ...)` 会占掉 `/assets/*filepath` 这块路由，不能再用 `/assets/:id` 注册另一套参数路由。公共资源放 `/assets`，业务接口放 `/api`，路径会清楚很多。

临时签名下载地址适合对象存储、大文件或限时授权，小文件下载不一定要用。普通附件接口、浏览器 Blob、签名 URL 按文件大小和授权方式选。

参考：[静态文件](https://gin-gonic.com/en/docs/rendering/serving-static-files/)、[FileAttachment](https://pkg.go.dev/github.com/gin-gonic/gin@v1.12.0#Context.FileAttachment)。
