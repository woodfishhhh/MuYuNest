给定一个仅由字符 `a` 和 `b` 组成的字符串 `s`，长度为 `n`。可以删除**一段连续的子串**（可以为空），使得剩余字符串中 `a` 的数量等于 `b` 的数量。求**最少需要删除的字符个数**；如果只能把整个字符串全部删掉才能平衡，输出 `-1`。

## 转化问题：权和模型

**核心思路：把 `a` 映射为 `+1`、`b` 映射为 `-1`，于是“删掉子串后剩余 `a` 与 `b` 数量相等”等价于“删掉一段区间和恰好等于总权和 `sum` 的最短子串”。**

将字符 `a` 视为 `+1`，字符 `b` 视为 `-1`，可以得到整个字符串的权和 $sum = cnt_a - cnt_b$。例如 `bbbba` 对应的权值序列是 `-1 -1 -1 -1 1`，总权和为 `-3`。

题目的要求是剩余部分中 `$a$` 的数量需要等于 `$b$` 的数量，也就是剩余字符串的**权和为 $0$**。

为了方便处理空前缀与 1-based 下标，在字符串前补一个占位字符，定义前缀和数组 `pre`（`pre[0] = 0`）：

```cpp
pre[0] = 0;
for (int i = 1; i <= n; i++) {
    pre[i] = pre[i - 1];
    if (s[i] == 'a') pre[i]++;
    else if (s[i] == 'b') pre[i]--;
}
```

如果本来 `sum == 0`，不需要删除任何字符，直接输出 `0`。

否则假设删除子串 `s[l..r]`，剩余部分的权和为 `sum - (pre[r] - pre[l - 1])`。我们希望剩余权和为 `0`，即：

$$sum - (pre[r] - pre[l - 1]) = 0 \implies pre[r] - pre[l - 1] = sum$$

问题变成：在 `pre[0..n]` 中找下标对 `(i, j)`（满足 `0 <= i < j <= n`）使得 `pre[j] - pre[i] = sum`，并令删除长度 `j - i` 最小。

## 哈希表维护最近位置

因为我们要让 `j - i` 最小，对于每个前缀和值，哈希表里只需要记录它**最后一次出现的位置**即可：

1. 初始化 `mp[0] = 0`，`ans = n`。
2. 遍历 `j` 从 `1` 到 `n`：
   - 计算目标前缀和 `need = pre[j] - sum`。
   - 若 `need` 在 `mp` 中存在，更新最短删除长度 `ans = min(ans, j - mp[need])`。
   - 更新当前前缀和的最新下标：`mp[pre[j]] = j`。
3. 边界判断：由于题目保证空串平衡，全删一定合法，所以若最终 `ans == n`，说明只能把整串删空，按题意输出 `-1`；否则输出 `ans`。
