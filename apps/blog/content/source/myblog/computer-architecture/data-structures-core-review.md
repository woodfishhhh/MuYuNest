数据结构期末或统考压轴计算题高度集中在几类固定模型：KMP 的 `next` / `nextval` 手算、二叉树与树的度节点推导、BST 平均查找长度（尤其是不成功 ASL）、哈夫曼 WPL 速算、哈希冲突探测以及七大排序算法的稳定性与趟数推演。下面把每一块的手推模板、公式和必避坑点集中整理成可直接上手的速查手册。

## 1. 模式匹配（KMP）手推 `next` 与 `nextval`

**`next[0] = -1`、`next[1] = 0` 与 `nextval[0] = -1` 恒定不变；求 `next[i]` 看 `T[0..i-1]` 的最长相等真前后缀长度，求 `nextval[i]` 只需看 `T[i]` 是否等于 `T[next[i]]`：相等就抄 `nextval[next[i]]`，不等就留 `next[i]`。**

### 核心解题四行表法

需构建 4 行表格（列数为关键字长度 + 1）：

1. 第 1 行（下标）：从 `0` 开始依次递增。
2. 第 2 行（模式串字符）：逐字符抄入 `T[0..n-1]`。
3. 第 3 行（`next` 数组）：`next[0] = -1`、`next[1] = 0`；对 $i \ge 2$，找 `T[0..i-1]` 最长相等真前缀与真后缀的长度 $k$（即满足 `T[0..k-1] == T[i-k..i-1]` 的最大 $k < i$），令 `next[i] = k`；若无则取 `0`。
4. 第 4 行（`nextval` 数组）：`nextval[0] = -1`；对每个 $i \ge 1$ 记 $k = next[i]$：
   - 若 `T[i] == T[k]`，则 `nextval[i] = nextval[k]`（防止无意义的同字符重复回退）；
   - 若 `T[i] != T[k]`，则 `nextval[i] = k`。

**例题**：已知模式串 `T = "ababacaaad"`：

- 计算 `next[3]`（`T[3] = 'b'`）：前子串 `T[0..2] = "aba"`，长度为 2 的前缀 `"ab"` 与后缀 `"ba"` 不等；缩小至长度 1，前缀 `"a"` 与后缀 `"a"` 相等，故 `next[3] = 1`。
- 计算 `nextval[2]`（`T[2] = 'a'`）：已知 `next[2] = 0`，由于 `T[2] == T[0] == 'a'`，故 `nextval[2] = nextval[0] = -1`。

## 2. 二叉树构建与中序线索化

**前序或后序必须搭配“中序遍历序列”才能唯一还原二叉树；中序线索化时把原本为空的左指针改成中序前驱、空右指针改成中序后继。**

### 基于遍历序列重构二叉树

- **中序 + 后序**：后序序列**最后一个**元素必为当前子树根节点；在中序序列中找到该根，左侧即为左子树节点集、右侧即为右子树节点集；按各自节点数切分后序序列，递归构建。
- **前序 + 中序**：前序序列**第一个**元素必为当前子树根节点；在中序中定位根，左子树有 $k$ 个节点，则前序中紧随根后的 $k$ 个元素对应左子树、其余对应右子树，递归构建。

### 中序线索二叉树

中序遍历顺序为“左 → 根 → 右”。节点有左孩子时左指针留作孩子指针，**无左孩子**时左指针指向中序前驱；**无右孩子**时右指针指向中序后继。例如中序序列 `a→b→c→d→e→f→g→h→i`：

1. `a` 无左孩子（中序首节点无前驱，左指针为 `NULL`），无右孩子则右指针指 `b`；
2. `b` 有左孩子 `a`（保持左孩子指针），无右孩子则右指针指 `c`；
3. `c` 无左孩子指前驱 `b`、无右孩子指后继 `d`，以此类推直至全树线索化完毕。

## 3. 树的节点度数与叶子节点个数公式

**任何树都同时满足“总结点数 = 各度数节点数之和”与“总结点数 = 总分支数（总度数之和）+ 1”，两式相减即可瞬间消去 $n_1$ 求出叶子节点数 $n_0$。**

以度为 3 的树为例，设 $n_i$ 为度为 $i$ 的节点数：

$$n = n_0 + n_1 + n_2 + n_3$$

$$n = 0 \times n_0 + 1 \times n_1 + 2 \times n_2 + 3 \times n_3 + 1$$

**例题**：已知某度为 3 的树中 $n_2 = 200,\ n_3 = 100$，求叶子节点数 $n_0$：

1. $n = n_0 + n_1 + 200 + 100 = n_0 + n_1 + 300$
2. $n = n_1 + 2 \times 200 + 3 \times 100 + 1 = n_1 + 701$
3. 联立消去 $n_1$：$n_0 + 300 = 701 \implies n_0 = \mathbf{401}$。

## 4. 二叉排序树（BST）构建、ASL 计算与删除

**算 BST 查找成功 ASL 分母是节点数 $n$；算查找不成功 ASL 必须补全全部 $n + 1$ 个外节点（空指针 `NULL`），分母是 $n + 1$，每个空指针的比较次数等于它父节点所在的层数。**

### 构建规则与示例

核心有序性：**左子树所有节点值 < 根节点值 < 右子树所有节点值**（通常默认元素互异）。依次读取序列 `K = {34, 76, 45, 18, 26, 54, 92, 38}`：

```text
       34 (L1)
      /  \
 (L2)18   76
      \   /  \
 (L3) 26 45   92
        /  \
 (L4)  38   54
```

### 查找次数与平均查找长度（ASL）

- 查找 `54`（成功）：`34 → 76 → 45 → 54`，比较 `4` 次。
- 查找 `100`（失败）：`34 → 76 → 92 → NULL`，共与 3 个节点比过，比较 `3` 次。

1. **查找成功 $ASL_{\text{success}}$**：公式 $\frac{\sum (\text{本层节点数} \times \text{层数})}{n}$。各层节点数为 L1(1)、L2(2)、L3(3)、L4(2)：

$$ASL_{\text{success}} = \frac{1 \times 1 + 2 \times 2 + 3 \times 3 + 4 \times 2}{8} = \frac{22}{8} = 2.75$$

2. **查找不成功 $ASL_{\text{unsuccess}}$（补坑法）**：整棵树有 $n = 8$ 个节点，故共有 $n + 1 = 9$ 个空指针（失败落点）：
   - L2 节点 `18` 的左空指针（1 个）→ 到 `18` 比较 `2` 次；
   - L3 节点 `26` 左右、`92` 左右空指针（共 4 个）→ 比较 `3` 次；
   - L4 节点 `38` 左右、`54` 左右空指针（共 4 个）→ 比较 `4` 次；

$$ASL_{\text{unsuccess}} = \frac{1 \times 2 + 4 \times 3 + 4 \times 4}{9} = \frac{30}{9} \approx 3.33$$

### BST 节点的删除操作

| 待删节点情况 | 操作方法 |
| --- | --- |
| **度为 0（叶子）** | 直接删除，父节点对应指针置 `NULL` |
| **度为 1（单孩子）** | 让唯一孩子直接顶替待删节点位置 |
| **度为 2（双孩子）** | 找替身转化为删度 0/1 节点：① 找中序后继（右子树最左节点）或 ② 找中序前驱（左子树最右节点），用替身值覆盖当前节点后删除原替身节点 |

例如在上面 BST 中删除 `76`，既可以用右子树的最小值 `92` 顶替，也可以用左子树的最大值 `54` 顶替。

## 5. 广义表与数组存储地址计算

**广义表的表尾永远是一个带括号的子表（即使只剩一个元素也要包括号），深度等于最深嵌套括号层数；二维数组按行优先定位时，记住下标从 0 还是从 1 开始即可套公式秒算。**

### 广义表核心概念

以广义表 `L = (a, (b), (c, (d,e,f)))` 为例：

| 概念 | 定义规则 | 示例结果 |
| --- | --- | --- |
| **表头（Head）** | 最外层第一个元素（可为原子或子表） | `a` |
| **表尾（Tail）** | 去掉表头后其余元素**外加一层括号**构成的广义表 | `((b), (c, (d,e,f)))` |
| **长度** | 最外层元素总个数 | `3` |
| **深度** | 嵌套括号的最大层数（原子深度 0，空表 `()` 深度 1） | `3` |

存储结构图画法：方框节点用标志位 `1` 表示子表、`0` 表示原子；同一层并列节点用尾指针串联，末尾指向 `NULL`。

### 二维数组地址公式

对于 $m$ 行 $n$ 列、下标从 `1` 开始的二维数组（行优先存储），每个元素占 $k$ 个存储单元：

$$LOC(a[i][j]) = LOC(a[1][1]) + [(i - 1) \times n + (j - 1)] \times k$$

**例题**：`A[1..3][1..4]` 首地址 $LOC(A[1][1]) = 2000$，$k = 2$，求 $LOC(A[2][3])$：

$$LOC(A[2][3]) = 2000 + [(2 - 1) \times 4 + (3 - 1)] \times 2 = 2000 + 6 \times 2 = 2012$$

## 6. 二叉树高频递归代码模板

```c
typedef struct TreeNode {
    int data;
    struct TreeNode *left;
    struct TreeNode *right;
} TreeNode;

// 1. 统计二叉树节点总数
int countNodes(TreeNode *b) {
    if (b == NULL) return 0;
    return countNodes(b->left) + countNodes(b->right) + 1;
}

// 2. 计算二叉树高度
int treeHeight(TreeNode *b) {
    if (b == NULL) return 0;
    int leftH = treeHeight(b->left);
    int rightH = treeHeight(b->right);
    return (leftH > rightH ? leftH : rightH) + 1;
}

// 3. 输出全部叶子节点
void printLeaves(TreeNode *b) {
    if (b == NULL) return;
    if (b->left == NULL && b->right == NULL) {
        printf("%d ", b->data);
    }
    printLeaves(b->left);
    printLeaves(b->right);
}
```

## 7. 哈夫曼树与带权路径长度（WPL）

**哈夫曼树每次合并权值最小的两棵子树，最终 WPL 不仅等于 $\sum(\text{叶子权值} \times \text{编码长度})$，还恒等于构造过程中所有“非叶子分支节点权值”之和——用来验算选择题又快又准。**

已知叶子权重 `[2, 3, 6, 7, 10, 19, 21, 32]`（左 `0` 右 `1`）：

1. **逐轮合并产生的新非叶子节点权值**：
   - `2 + 3 = 5` → 剩余 `[5, 6, 7, 10, 19, 21, 32]`
   - `5 + 6 = 11` → 剩余 `[7, 10, 11, 19, 21, 32]`
   - `7 + 10 = 17` → 剩余 `[11, 17, 19, 21, 32]`
   - `11 + 17 = 28` → 剩余 `[19, 21, 28, 32]`
   - `19 + 21 = 40` → 剩余 `[28, 32, 40]`
   - `28 + 32 = 60` → 剩余 `[40, 60]`
   - `40 + 60 = 100`（根）
2. **WPL 验证**：
   - 按叶子计算：$(2+3)\times 5 + (6+7+10)\times 4 + (19+21+32)\times 2 = 25 + 92 + 144 = \mathbf{261}$；
   - 按非叶子节点求和速算：$5 + 11 + 17 + 28 + 40 + 60 + 100 = \mathbf{261}$。

## 8. 图的遍历与最小生成树（Prim / Kruskal）

**DFS 沿着一条支路一头扎到底再回溯（对应栈/递归），BFS 按距离层层向外推进（对应队列）；Prim 从顶点集合扩张适合稠密图，Kruskal 按边权排序加并查集判环适合稀疏图。**

### 最小生成树推演（节点 `0~5`）

边权：`(0,1)=1`、`(0,3)=2`、`(1,2)=3`、`(1,4)=4`、`(4,5)=4`、`(0,2)=5`、`(2,5)=6`、`(3,5)=8`。

- **Prim（从 `0` 出发）**：`{0}` 选 `(0,1)=1` → `{0,1}` 选 `(0,3)=2` → 选 `(1,2)=3` → 选 `(1,4)=4` → 选 `(4,5)=4`（注：若按部分手工顺序先选权大边会错，Prim 每次必选连接已选集与未选集的**全局最小跨边**！上面先选 `(1,4)=4` 再选 `(4,5)=4` 总权重 $1+2+3+4+4 = 14$；若原图不存在 `(1,4)` 或权更大时才轮到 `(2,5)=6` 权重 `16`，做题时务必在候选割边表里比全再选最小）。
- **Kruskal（按边权升序）**：`(0,1)=1` → `(0,3)=2` → `(1,2)=3` → `(1,4)=4` → `(4,5)=4`，边数达到 $6 - 1 = 5$ 条且无环即止。

### DFS 与 BFS 遍历示例

对于含边 `1-2-3-4`、`1-5`、`1-6` 的无向图，从 `1` 出发：

- **DFS**：可走 `1→2→3→4→5→6` 或 `1→5→2→3→4→6`（取决于邻接表存储顺序）。
- **BFS**：逐层访问，序列为 `1 → 2 → 5 → 6 → 3 → 4`。

## 9. 哈希表与冲突处理

**开放定址法（线性/二次探测）遇到删除只能做逻辑删除标记，不能直接清空槽位，否则会截断后面同义词的查找探测链；算成功 ASL 分母是表内元素个数 $n$，算不成功 ASL 分母是哈希取余模数 $p$（或开放定址表的表长 $m$，审清“查找失败停在第一个空槽，空槽也计入 1 次比较”）。**

### 三类冲突处理机制

1. **线性探测法**：$H_i = (H(key) + i) \% m\ (i=1,2,\dots)$。查到表尾下标 $m-1$ 后回绕到下标 `0` 继续探测。最大缺陷是**一次聚集（堆积）现象**——冲突元素抱团形成连续非空块，连累非同义词也一路顺延探测。
   - **例**：表长 `5`，$H(key)=key\%5$，依次插入 `5(→0)`、`10(0被占→1)`、`11(1被占→2)`，查找 `11` 需比较下标 `1, 2` 共 `2` 次。
2. **二次探测法**：增量序列交替取 $+1^2, -1^2, +2^2, -2^2, \dots$，公式 $d_i = (H(key) \pm k^2) \% m$。**负数取模记得加 $m$ 转正**（如 $m=13,\ H=1$，减 $2^2$ 得 $-3 \equiv 10 \pmod{13}$）。优点是大幅缓解堆积；为保证表未满时能探测到空位，表长 $m$ 通常取形如 $4k+3$ 的素数。
3. **链地址法（拉链法）**：冲突元素统一挂在对应下标的单链表中（常头插）。设 $H(key) = key \% 13$，序列 `{1, 14, 27, 2}` 头插后结构：

```text
下标
[0] -> NULL
[1] -> 27 -> 14 -> 1 -> NULL
[2] -> 2 -> NULL
[3] -> NULL
```

此时查找成功比较次数分别为：第 1 层 `27, 2` 各 1 次，第 2 层 `14` 2 次，第 3 层 `1` 3 次：

$$ASL_{\text{成功}} = \frac{1 \times 2 + 2 \times 1 + 3 \times 1}{4} = \frac{7}{4} = 1.75$$

### 冲突处理方式对比

| 特性 | 线性探测法 | 二次探测法 | 链地址法（拉链法） |
| --- | --- | --- | --- |
| **冲突增量** | $+1, +2, +3, \dots$ | $+1^2, -1^2, +2^2, -2^2, \dots$ | 挂入同义词单链表 |
| **堆积现象** | 严重 | 较轻 | **无**（非同义词绝不碰撞） |
| **删除操作** | 困难（只能打逻辑删除标记） | 困难（需逻辑删除标记） | **简单**（直接链表摘节点） |
| **平均查找性能** | 较差 | 中等 | **最高** |

做题易错点提醒：公式 $H(key) = key \% p$ 中若题目同时给出表长 $m=16$ 和除数 $p=13$，计算哈希地址时务必用 $p$ 取余、但计算失败落位和探查边界时以表长 $m$ 为模数（查空槽停下时记住：不成功比较次数计算分母按题目给出的有效模范围 $p$ 或表长核对，且空槽本身计 1 次比较）。

## 10. 内部排序核心对比与手写推演

**口诀“快希选堆”不稳定，其余（直接插入、冒泡、归并、基数）均稳定；输入基本有序时直接插入排序最快（$O(n)$），反而此时以首元素为轴的快速排序退化到最坏 $O(n^2)$。**

### 常见排序过程核心要点

- **直接插入排序**：第 $i$ 趟保证前 $i+1$ 个元素局部有序，后面未扫描元素保持原位。
- **希尔排序**：按增量 $d$ 分组做直接插入，最后一趟 $d=1$，因跨组跳跃交换而不稳定。
- **冒泡排序**：每趟两两交换把最大（或最小）沉到末端，若某趟零交换可提前结束。
- **快速排序（双指针填坑法）**：以序列 `[34, 50, 25, 23, 56, 20]` 基准 `34` 为例：`R` 找小 `20` 填 `L` 坑 → `L` 找大 `50` 填 `R` 坑 → `R` 找小 `23` 填 `L` 坑 → `L` 扫过 `25` 与 `R` 相遇后填入 `34`，一趟后得 `[20, 23, 25, 34, 56, 50]`（基准左侧全 $\le 34$、右侧全 $\ge 34$）。
- **简单选择排序**：每趟选无序区最小元素与无序区首元素交换，比较次数恒为 $\frac{n(n-1)}{2}$。如 `[2, 2', 1]` 第一趟 `1` 与 `2` 交换变为 `[1, 2', 2]`，破坏稳定性。
- **堆排序**：从最后一个非叶子节点 $\lfloor n/2 \rfloor$ 自下而上建大顶堆，每次把堆顶与末尾交换后向下调整。空间 $O(1)$、时间恒定 $O(n \log n)$，适合海量数据选 Top-$K$。
- **2-路归并排序**：稳定且最坏时间仍为 $O(n \log n)$，代价是需要 $O(n)$ 辅助数组。

### 七大排序性能速背表

| 排序算法 | 平均时间 | 最好时间 | 最坏时间 | 辅助空间 | 稳定性 | 适用场景 |
| --- | --- | --- | --- | --- | --- | --- |
| **直接插入** | $O(n^2)$ | $O(n)$ | $O(n^2)$ | $O(1)$ | 稳定 | 小规模、基本有序序列最快 |
| **希尔排序** | $O(n^{1.3})$ | — | $O(n^2)$ | $O(1)$ | **不稳定** | 中等规模增量预排 |
| **冒泡排序** | $O(n^2)$ | $O(n)$ | $O(n^2)$ | $O(1)$ | 稳定 | 教学或几乎有序小表 |
| **快速排序** | $O(n \log n)$ | $O(n \log n)$ | $O(n^2)$ | $O(\log n)$ | **不稳定** | 综合平均性能最佳 |
| **简单选择** | $O(n^2)$ | $O(n^2)$ | $O(n^2)$ | $O(1)$ | **不稳定** | 移动次数少但比较固定 |
| **堆排序** | $O(n \log n)$ | $O(n \log n)$ | $O(n \log n)$ | $O(1)$ | **不稳定** | 内存紧张、Top-$K$ |
| **归并排序** | $O(n \log n)$ | $O(n \log n)$ | $O(n \log n)$ | **$O(n)$** | 稳定 | 要求稳定且外排序基础 |

### 稳定性判别模拟题

数据 `[12, 2, 16, 30, 28, 10, 16*, 20, 6, 18]` 排序后变为 `[2, 6, 10, 12, 16, 16*, 18, 20, 28, 30]`（两个 `16` 相对顺序未变），问哪项**不可能**是所用算法？
A. 冒泡排序  B. 快速排序  C. 归并排序  D. 直接插入排序

<details>
<summary>点击查看解析</summary>

**答案：B（快速排序）**。排序结果保持了相等元素 `16` 与 `16*` 的原始前后顺序，说明所用算法具有稳定性（或者在稳定排序中必定成立）；冒泡、归并、直接插入均稳定，只有快速排序是不稳定排序，故选 B。
