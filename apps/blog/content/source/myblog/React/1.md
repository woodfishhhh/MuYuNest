## 二、React 项目创建
### 1. 两种创建方式
#### （1）先用官方脚手架
```bash
npx create-react-app 项目名
```
- 它只搭好基础 React 环境，不会预装路由、状态管理等功能。
- 底层构建工具是 Webpack。
- 命令执行后会直接生成最简项目，没有交互式配置。

#### （2）再看第三方集成脚手架
Umi 等脚手架会预先集成路由、Mock、请求封装等功能，在企业项目里比较常见。不同公司的选型并不一致，学习阶段先不依赖这套集成。

### 2. 项目启动命令
```bash
npm start
# 或
npm run start
```

## 三、项目目录结构
### 1. 先看两个目录
#### public（静态资源目录）
- 这里存放 HTML 模板、静态图片、 favicon 等内容。
- 入口模板是 `index.html`。
  - 里面有挂载节点：`<div id="root"></div>`。
  - 它对应 Vue 中的 `#app` 节点。

#### src（业务代码目录）
这里没有预设的业务子目录，代码结构需要自己组织。

### 2. src 里的入口文件
| 文件 | 作用 | 对应 Vue |
|------|------|----------|
| `App.js` | 根组件 | `App.vue` |
| `index.js` | 项目入口，执行挂载 | `main.js` |
| `App.css` | 根组件样式 | - |
| `index.css` | 全局样式 | - |

### 3. 暂时用不到的文件
- `App.test.js` 用于组件单元测试。
- `setupTests.js` 保存测试启动配置。
- `reportWebVitals.js` 用于项目性能监控。

## 四、React 和 react-dom 怎么分工
### 1. 两个依赖各管一件事
#### （1）react
- 提供组件、虚拟 DOM、生命周期、Hooks 等能力。
- 它负责**组件逻辑定义**，不直接操作真实 DOM。

#### （2）react-dom
- 负责**组件 ↔ 真实 DOM** 之间的挂载、卸载和渲染。
- 这部分对应 Vue 中的 `createApp(App).mount('#app')`。

### 2. 挂载与卸载原理
#### 标准挂载代码
```jsx
import React from 'react'
import ReactDOM from 'react-dom/client'
import App from './App'

const root = ReactDOM.createRoot(document.getElementById('root'))
root.render(<App />)
```

#### 卸载示例
```jsx
setTimeout(() => {
  root.unmount()
}, 2000)
```
2秒后页面会被清空，这个结果可以直接看到 `react-dom` 对真实 DOM 的渲染和销毁。

## 五、组件体系与 Vue 对比
### 1. 根组件机制
- React **只有根组件 `App.js`**，没有 Vue 式根实例。
- 其他页面和组件都挂在 `App` 下面。

### 2. 文件结构差异
- Vue：单文件组件 `.vue`（template + script + style）
- React：
  - 结构 + 逻辑：`.js` / `.jsx`
  - 样式：放在独立 `.css` 文件中，再手动引入。

## 六、把项目调用链串起来
1. **库的分工**
React 负责组件逻辑，ReactDOM 负责连接 DOM，Vue 中两者合一。

2. **挂载顺序**
获取 `#root` DOM → 创建 root 对象 → 渲染根组件。

3. **最简目录链路**
public/index.html → src/index.js → src/App.js。

4. **后面会遇到的渲染问题**
- 父组件更新 → 子组件默认全部重新渲染。
- 可以用 `React.memo` / `useMemo` / `useCallback` 优化，后续课程会展开。

5. **组件写法**
- 企业项目主流是 React + TypeScript（TSX）。
- 学习顺序是先类组件 → 后函数组件 + Hooks。
