## 一、表单数据怎么来回流动
React 的表单处理仍然遵循 **原生 JS 操作逻辑**：事件负责取值，属性负责把值写回视图。把这两步接到 state 上，数据和表单就能保持同步：
**双向绑定 = （事件监听 → 数据更新） + （数据绑定 → 视图更新）**

## 二、受控和非受控，区别在谁保存值
### 1. 受控组件（多数场景优先）
- 表单的值由 React 响应式数据（state）控制，开发者可以主动修改表单值
- 用 `value`（输入框/下拉框）或 `checked`（单选/复选框）读取 state，再在事件里更新 state
- 数据和视图始终同步，所以实时校验、格式化输入都比较顺手
- 需要实时处理表单数据时使用，例如实时验证、联动表单

### 2. 非受控组件
- 表单的值留在 DOM 内部维护，开发者只在需要时通过事件读取，不主动设置表单值
- 不绑定 `value`/`checked` 属性，只监听 `input`/`change` 事件并读取 `event.target.value`
- 写法更省事，也不用额外维护 state
- 适合一次性提交的简单表单，例如不需要实时处理数据的登录表单

## 三、不同表单元素怎么绑定
### 1. 普通输入框（input[type="text"]）
#### （1）非受控组件（仅取值）
```jsx
// 监听 change 事件，输入完成失焦后获取值
<input
  type="text"
  onChange={(e) => {
    const inputValue = e.target.value; // 获取输入值
    console.log("输入值：", inputValue);
  }}
/>
```

#### （2）受控组件（双向绑定）
```jsx
import { useState } from 'react';

function InputBind() {
  // 1. 定义响应式数据
  const [inputValue, setInputValue] = useState('');

  // 2. 监听 input 事件，实时更新数据（也可使用 change 事件）
  const handleInputChange = (e) => {
    setInputValue(e.target.value); // 数据更新
  };

  // 3. value 绑定数据，视图更新
  return (
    <div>
      <input
        type="text"
        value={inputValue} // 绑定 state
        onChange={handleInputChange} // 监听事件
      />
      <p>实时显示：{inputValue}</p>
    </div>
  );
}
```

### 2. 复选框（checkbox）
#### （1）单个复选框（如「同意协议」）
```jsx
import { useState } from 'react';

function SingleCheckbox() {
  const [isAgree, setIsAgree] = useState(false); // 布尔值存储选中状态

  const handleCheck = (e) => {
    setIsAgree(e.target.checked); // 通过 checked 获取状态
  };

  return (
    <label>
      <input
        type="checkbox"
        checked={isAgree} // 绑定选中状态
        onChange={handleCheck}
      />
      同意用户协议
    </label>
  );
}
```

#### （2）多个复选框（如「兴趣选择」）
```jsx
import { useState } from 'react';

function MultiCheckbox() {
  // 数组存储选中的 value 集合
  const [checkedValues, setCheckedValues] = useState([]);

  const handleCheck = (e) => {
    const { value, checked } = e.target;
    let newCheckedValues = [...checkedValues]; // 拷贝原数组（React 不可直接修改状态）

    if (checked) {
      // 勾选：添加 value 到数组
      newCheckedValues.push(value);
    } else {
      // 取消勾选：从数组中删除 value
      newCheckedValues = newCheckedValues.filter(item => item !== value);
    }

    setCheckedValues(newCheckedValues);
  };

  // 同一组复选框需设置相同 name
  return (
    <div>
      <label>
        <input type="checkbox" name="hobby" value="reading" onChange={handleCheck} checked={checkedValues.includes("reading")} />
        阅读
      </label>
      <label>
        <input type="checkbox" name="hobby" value="coding" onChange={handleCheck} checked={checkedValues.includes("coding")} />
        编程
      </label>
      <label>
        <input type="checkbox" name="hobby" value="sports" onChange={handleCheck} checked={checkedValues.includes("sports")} />
        运动
      </label>
      <p>选中的兴趣：{checkedValues.join(", ")}</p>
    </div>
  );
}
```

### 3. 单选框（radio）
```jsx
import { useState } from 'react';

function RadioBind() {
  // 字符串存储选中的 value
  const [selectedValue, setSelectedValue] = useState('male');

  const handleRadioChange = (e) => {
    setSelectedValue(e.target.value); // 获取选中的 value
  };

  // 同一组单选框需设置相同 name
  return (
    <div>
      <label>
        <input type="radio" name="gender" value="male" onChange={handleRadioChange} checked={selectedValue === "male"} />
        男
      </label>
      <label>
        <input type="radio" name="gender" value="female" onChange={handleRadioChange} checked={selectedValue === "female"} />
        女
      </label>
      <p>选中的性别：{selectedValue}</p>
    </div>
  );
}
```

### 4. 下拉框（select）
```jsx
import { useState } from 'react';

function SelectBind() {
  const [selectedCity, setSelectedCity] = useState('shanghai');

  const handleSelectChange = (e) => {
    setSelectedCity(e.target.value); // 获取选中的 value
  };

  return (
    <div>
      <select value={selectedCity} onChange={handleSelectChange}>
        <option value="beijing">北京</option>
        <option value="shanghai">上海</option>
        <option value="guangzhou">广州</option>
        <option value="shenzhen">深圳</option>
      </select>
      <p>选中的城市：{selectedCity}</p>
    </div>
  );
}
```

## 四、几个容易出错的地方
1. **先选对事件**：
   - `input` 事件：实时触发（输入时立即响应），适合实时同步数据
   - `change` 事件：失焦或选择完成后触发（如下拉框选择），适合减少触发频率
2. **更新状态时别改原值**：
   - 不可直接修改 state（如 `checkedValues.push(value)` 错误），需通过拷贝生成新状态（`[...checkedValues]`）
3. **取值和设值要对应表单类型**：
   | 表单元素       | 取值属性   | 设值属性   | 状态存储类型 |
   |----------------|------------|------------|--------------|
   | 普通输入框     | value      | value      | 字符串       |
   | 复选框（单个） | checked    | checked    | 布尔值       |
   | 复选框（多个） | value+checked | checked    | 数组（value集合） |
   | 单选框         | value      | checked    | 字符串（value） |
   | 下拉框         | value      | value      | 字符串（value） |
4. **和 Vue 的写法不同**：
   - Vue 可通过 `v-model` 一步完成双向绑定，React 需要手动绑定 `value` 和事件，因此每一步都能单独控制
   - Vue 默认监听 `input` 事件，React 可自由选择 `input`/`change` 等事件
