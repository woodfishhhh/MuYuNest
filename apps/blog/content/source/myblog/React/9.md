## 一、先看执行阶段
React 类组件会依次经历**挂载 → 更新 → 卸载**三阶段，没有单独的 create 阶段。
$$
\text{生命周期流程} = \text{挂载} \rightarrow \text{更新} \rightleftharpoons \text{更新} \rightarrow \text{卸载}
$$

---

## 二、挂载阶段（首次渲染）
### 执行顺序
$$
\text{constructor} \rightarrow \text{getDerivedStateFromProps} \rightarrow \text{render} \rightarrow \text{componentDidMount}
$$

1. **constructor**
- 负责类组件初始化、绑定 this 和初始化 state
- 严格来说它不是生命周期钩子，但初始化类组件时必须执行
2. **static getDerivedStateFromProps(props, state)**
- 这是一个静态方法，挂载和更新时都会触发
- 必须 return 新 state 或 null
- 实际使用很少
3. **render**
- 它决定组件最终渲染什么内容
- 不要在这里修改 state、发异步请求或操作 DOM
- 挂载和更新时都会执行
4. **componentDidMount**
- 组件挂载到 DOM 后触发
- 请求、DOM 操作和 ECharts 初始化可以放在这里
- 在 Vue 中对应 mounted

---

## 三、更新阶段（state/props 变化）
### 执行顺序
$$
\text{getDerivedStateFromProps} \rightarrow \text{shouldComponentUpdate} \rightarrow \text{render} \rightarrow \text{getSnapshotBeforeUpdate} \rightarrow \text{componentDidUpdate}
$$

1. **shouldComponentUpdate(nextProps, nextState)**
- 这个钩子决定组件是否继续更新
- 返回 false 会终止后续更新生命周期
- 返回 true 则继续更新
2. **getSnapshotBeforeUpdate**
- 在更新前获取 DOM 快照
- 实际使用很少
3. **componentDidUpdate(prevProps, prevState, snapshot)**
- 更新完成后触发
- 适合处理更新后的 DOM 操作和请求
- 在 Vue 中对应 updated

---

## 四、卸载阶段
### 这个阶段只有一个钩子
$$
\text{componentWillUnmount}
$$
- 组件即将销毁时触发
- 定时器、事件和订阅都要在这里清理
- 在 Vue 中对应 destroyed

---

## 五、严格模式（StrictMode）
- 它只在开发环境生效，生产环境会自动移除
- 主要用来检测废弃 API 和副作用
- 开启后，生命周期和 render 会执行**两次**
- 要关闭它，去掉 index.js 中 <React.StrictMode>

---

## 六、减少没有必要的更新
### 1. 用 shouldComponentUpdate 判断是否更新
```js
shouldComponentUpdate(nextProps, nextState) {
  // 对比新旧 state/props
  if (this.state.msg === nextState.msg) {
    return false; // 不更新
  }
  return true;
}
```

### 2. PureComponent
- 它会浅对比 props/state，没有变化就不更新
- 不要和 shouldComponentUpdate 同时使用
- 两者的关系可以写成：
$$
\text{PureComponent} = \text{Component} + \text{默认浅对比优化}
$$

### 3. 父组件更新也会带动子组件
- React 没有依赖收集，父组件更新 → 子组件无条件更新
- 子组件可以用 PureComponent / React.memo 减少这类更新

---

## 七、把逻辑放到合适的钩子里
1. **render**：只负责渲染，不写业务逻辑
2. **componentDidMount**：处理初始化请求和 DOM
3. **componentDidUpdate**：处理更新后的操作
4. **componentWillUnmount**：组件卸载前必须清理资源
5. **禁止**：不要在 render 中 setState，否则会进入死循环

---

## 八、Vue ↔ React 生命周期对照
| Vue | React |
|---|---|
| beforeCreate | constructor |
| mounted | componentDidMount |
| beforeUpdate | getSnapshotBeforeUpdate |
| updated | componentDidUpdate |
| destroyed | componentWillUnmount |
