## 一、先看组件里有什么
1. 组件首先要描述 UI 结构，也就是 HTML 模板。数据负责保存组件状态或配置，方法负责交互和数据处理；没有数据和方法也能写出基础组件，但实际项目通常少不了它们。
2. React/Vue 都会把页面拆成独立、可复用的功能单元。组件边界清楚后，修改和复用都更省事。

## 二、React 组件有两种写法
### （一）函数组件（新版本推荐，对应 Vue3 组合式 API）
1. 函数组件就是一个 JavaScript 函数，返回值用来描述组件的 HTML 结构。
2. 写的时候注意两条规则：
   - 组件名首字母必须大写。小写名称会被 React 当成原生 DOM 标签，最终导致报错。
   - 通过 `return` 返回用 JSX 写的 HTML 模板。
3. 先看一个最小例子：
   ```jsx
   // 函数组件：首字母大写
   function FnHello() {
     return <div>Hello 函数组件</div>;
   }
   // 使用组件：尖括号包裹
   ReactDOM.render(<FnHello />, document.getElementById('root'));
   ```

### （二）Class 类组件（老版本写法，对应 Vue2 选项式 API）
1. Class 组件是一个 JavaScript 类，需要先继承 React 提供的基础类。
2. 它的规则比函数组件多一些：
   - 继承 `React.Component`（或 `React.PureComponent`）后，组件才能使用生命周期、接收 props 等能力。
   - 在构造函数 `constructor` 中调用 `super(props)`，继承父类属性并接收 props。
   - 实现 `render()` 方法，由它返回 HTML 模板。
   - 组件名同样要以大写字母开头。
3. 对应的代码如下：
   ```jsx
   // 引入 React（类组件依赖）
   import React from 'react';
   // Class 组件：继承 React.Component
   class ClassHello extends React.Component {
     constructor(props) {
       super(props); // 继承父类，接收 props
     }
     // 必须实现 render 方法返回模板
     render() {
       return <div>Hello Class 组件</div>;
     }
   }
   // 使用组件
   ReactDOM.render(<ClassHello />, document.getElementById('root'));
   ```

## 三、JSX 最后会变成什么
### （一）JSX 的作用
1. JSX 是 JavaScript XML 的缩写，它让我们可以直接在 JavaScript 中写出接近 HTML 的结构，也是 React 推荐的模板写法。
2. JSX 需要经过 webpack 等构建工具编译，直接写进未编译的 JS 文件会报错。
3. **JSX 是创建 React 元素（虚拟 DOM）的语法糖**。它不会直接进入页面，而是先被编译成 `React.createElement()` 调用。
4. React 和 JSX 并不绑定：React 可以绕过 JSX，用 `React.createElement()` 创建元素；JSX 也能交给其他框架（如 Vue）编译，生成对应框架的组件对象。

### （二）对照 React.createElement 看编译结果
1. JSX 编译后就是 `React.createElement()` 调用，两种写法都会得到 `React.Element` 类型的虚拟 DOM 对象。
2. 把两种写法放在一起更直观：
   ```jsx
   // 1. JSX 写法（简洁直观）
   const jsxElement = <div className="hello">Hello JSX</div>;

   // 2. React.createElement 写法（JSX 编译后的底层实现）
   const createElementElement = React.createElement(
     'div', // 元素类型（标签名/组件）
     { className: 'hello' }, // 元素属性
     'Hello JSX' // 子节点（文本/元素）
   );

   // 打印结果：二者完全相同的 React.Element 对象
   console.log(jsxElement === createElementElement); // false（引用不同），但结构、属性完全一致
   ```
3. 生成的虚拟 DOM 可以简化成下面这个结构：
   ```javascript
   {
     type: 'div', // 元素类型
     props: { className: 'hello', children: 'Hello JSX' }, // 属性与子节点
     $$typeof: Symbol.for('react.element') // React 元素标识
   }
   ```

## 四、JSX 中 `{}` 的渲染规则
`{}` 用来在 JSX 中嵌入 JavaScript 表达式，作用接近 Vue 的 `{{}}`，但不同类型的值会得到不同结果：

| 渲染内容类型       | 渲染结果                                                                 | 示例代码                                  |
|--------------------|--------------------------------------------------------------------------|-------------------------------------------|
| 字符串/数字        | 直接渲染对应值                                                           | `{ 'Hello' }` → 渲染为 "Hello"；`{ 123 }` → 渲染为 "123" |
| 数组               | 遍历数组，渲染每一项（自动拼接，无分隔符）                               | `{ [1, 2, <FnHello />] }` → 12Hello 函数组件 |
| 表达式（算术/三元）| 执行表达式，渲染结果                                                     | `{ 1 + 1 }` → 2；`{ true ? <FnHello /> : 123 }` → Hello 函数组件 |
| React Element 对象 | 正常渲染为对应的 DOM 结构                                               | `{ <FnHello /> }` → 渲染 FnHello 组件内容 |
| 普通对象           | 报错（React 不支持直接渲染普通对象）                                     | `{ { name: 'React' } }` → 控制台报错       |
| 函数               | 报错（无法直接渲染函数本身，需调用后返回 React 元素）                     | `{ FnHello }` → 报错；`{ FnHello() }` → 正常渲染 |
| 布尔值/null/undefined | 不渲染任何内容（静默处理，无报错）                                      | `{ true }`、`{ null }`、`{ undefined }` → 页面无显示 |

### 使用时容易漏掉的细节
1. JSX 没有 Vue 中的 `v-if` 指令，条件渲染通常直接写三元表达式。
2. 数组很适合拿来渲染列表，不过列表项要添加 `key` 属性，后面的列表循环章节会再展开。
3. 嵌入函数时要真正调用它（`{ 函数名() }`），并保证返回 React 元素或其他可渲染值。

## 五、组件怎么调用
1. 组件名首字母必须大写，React 靠这一点区分组件和原生 DOM 标签。
2. 调用时有两种形式：
   - 加尖括号 `<组件名 />`：React 会把它解析为 React Element 对象，可以直接渲染，也是推荐写法。
   - 不加尖括号直接调用：它会像普通函数一样执行并返回 React Element 对象，也能渲染，但可读性差，不推荐这样写：
     ```jsx
     // 两种方式均可渲染，效果一致
     ReactDOM.render(<FnHello />, root); // 推荐
     ReactDOM.render(FnHello(), root); // 不推荐
     ```
3. 无论函数组件还是类组件，最后都要返回 React Element 对象，React 再根据这个对象渲染真实 DOM。
