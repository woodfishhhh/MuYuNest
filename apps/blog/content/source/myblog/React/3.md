## 一、这篇先解决什么
- 学习顺序仍是先Class组件（老写法）→ 后函数组件（新写法），这里先把Class组件里的事件绑定讲清楚。
- 如果你已经有Vue或原生JS基础，可以直接对照语法差异来看。

## 二、先把事件写对
1. React 事件采用 `on+事件名` 的形式，**事件名首字母必须大写**。例如要写 `onClick`（非`onclick`）、`onChange`（非`onchange`），这点和原生JS不同。
2. `onXXX` 等号右侧要放**方法引用**，并用花括号 `{}` 包住JS表达式，不能传字符串，也不能在渲染时直接执行函数。
   - 正确示例：`<div onClick={this.handleClick}>` 或 `<div onClick={() => console.log(1)}>`
   - 错误示例：`<div onClick="handleClick()">`（字符串形式）、`<div onClick={this.handleClick()}>`（直接调用函数）

## 三、先写一个能点击的 Class 组件
1. 把函数组件改成Class组件时，需要继承 `React.Component`，并把模板写进 `render()` 函数：
   ```jsx
   class App extends React.Component {
     render() {
       return <div onClick={() => console.log("点击触发")}>点击测试</div>;
     }
   }
   ```
2. 事件逻辑可以直接写，也可以拆成类方法：
   - 写法1：逻辑很短时用内联匿名函数。
     ```jsx
     render() {
       return <button onClick={() => alert("按钮被点击")}>点击按钮</button>;
     }
     ```
   - 写法2：逻辑较多时绑定类中定义的方法，代码更容易维护。
     ```jsx
     class App extends React.Component {
       handleClick() {
         console.log("类方法触发");
       }
       render() {
         return <button onClick={this.handleClick}>点击按钮</button>;
       }
     }
     ```

## 四、为什么方法里的 this 会丢
### 1. 问题出在哪里
Class组件直接绑定类方法（如 `onClick={this.handleClick}`）时，方法内部的 `this` 默认指向 `undefined`，而不是组件实例，所以也就访问不到 `this.state`、`this.props` 等组件属性。

### 2. 三种处理方式（优先级：bind绑定 > 箭头函数包裹 > 方法箭头化）
#### 方案1：用 `bind` 绑定this（推荐，支持传参）
调用函数的 `bind` 方法，把 `this` 固定为组件实例，同时得到一个新的函数引用：
```jsx
class App extends React.Component {
  handleClick() {
    console.log("this指向组件实例：", this); // 正确指向App实例
  }
  render() {
    // 绑定this，生成新方法
    return <button onClick={this.handleClick.bind(this)}>点击按钮</button>;
  }
}
```

#### 方案2：用内联匿名箭头函数包一层
箭头函数的“this继承自外层作用域”特性可以保住组件实例，直接在里面调用方法即可：
```jsx
render() {
  // 箭头函数的this指向render函数的this（即组件实例）
  return <button onClick={() => this.handleClick()}>点击按钮</button>;
}
```
这里容易写错：如果换成普通匿名函数（非箭头函数），`this` 仍会指向 `undefined`：
```jsx
// 错误写法：this指向undefined
return <button onClick={function() { this.handleClick(); }}>点击按钮</button>;
```

#### 方案3：把类方法直接写成箭头函数
这样定义后，方法里的 `this` 会固定指向组件实例，渲染时不必再绑定：
```jsx
class App extends React.Component {
  // 方法本身为箭头函数，this固定指向组件实例
  handleClick = () => {
    console.log("this指向组件实例：", this);
  };
  render() {
    // 直接绑定方法引用，无需额外处理
    return <button onClick={this.handleClick}>点击按钮</button>;
  }
}
```

## 五、事件参数怎么传
### 1. 先守住方法引用
传参后，`onXXX` 绑定的仍然必须是**方法引用**。如果直接写 `this.handleClick(1,2)`，函数会在页面渲染时立刻执行。

### 2. 这里用 `bind` 传参
这套写法只用 `bind` 传参：它绑定 `this` 的同时也能带上自定义参数，顺序是 `bind(this, 参数1, 参数2, ...)`：
```jsx
class App extends React.Component {
  // 接收参数：先自定义参数，最后接收事件对象（若需）
  handleClick = (num1, num2, e) => {
    console.log("参数1：", num1, "参数2：", num2);
    console.log("事件对象：", e);
  };
  render() {
    // 用bind传递参数，this作为第一个参数，后续为自定义参数
    return <button onClick={this.handleClick.bind(this, 10, 20)}>传递参数</button>;
  }
}
```

## 六、事件对象（Event）获取
### 1. 拿到的是 SyntheticEvent
React传入的是**合成事件对象（SyntheticEvent）**，不是原生JS的 `Event` 对象，不过常用属性和方法都在。
- 极少数需要原生事件对象的场景，可以通过 `e.nativeEvent` 获取。

### 2. 参数位置
- 没有自定义参数时，事件对象会作为**唯一参数**传入方法：
  ```jsx
  handleClick = (e) => {
    console.log("合成事件对象：", e); // 直接接收事件对象
    console.log("原生事件对象：", e.nativeEvent);
  };
  render() {
    return <button onClick={this.handleClick}>获取事件对象</button>;
  }
  ```
- 有自定义参数时，事件对象放在**最后一个参数**，同时配合 `bind` 传参：
  ```jsx
  handleClick = (num, e) => {
    console.log("自定义参数：", num);
    console.log("事件对象：", e); // 最后一个参数为事件对象
  };
  render() {
    return <button onClick={this.handleClick.bind(this, 100)}>传参+事件对象</button>;
  }
  ```

### 3. 合成事件对象里常用的内容
| 属性/方法          | 作用                          |
|---------------------|-------------------------------|
| `e.target`          | 获取触发事件的DOM元素         |
| `e.stopPropagation()` | 阻止事件冒泡（同原生）        |
| `e.preventDefault()`  | 阻止默认行为（如表单提交、链接跳转） |
| `e.clientX`/`e.clientY` | 鼠标触发位置的坐标（相对视口） |

## 七、四个常见错误
1. **错误1：绑定时直接调用方法**
   - 错误写法：`<button onClick={this.handleClick()}>`
   - 后果：页面渲染时立即执行方法，点击事件无响应（绑定值为方法返回值，而非方法本身）。
   - 修正：`<button onClick={this.handleClick}>` 或 `<button onClick={() => this.handleClick()}>`

2. **错误2：没有处理this指向**
   - 错误写法：未处理this，直接调用 `this.setState()` 或 `this.props`
   - 后果：报错 `Cannot read property 'setState' of undefined`
   - 修正：采用上述三种this绑定方案之一。

3. **错误3：事件名首字母写成小写**
   - 错误写法：`<div onclick={this.handleClick}>`
   - 后果：事件无法触发（React无法识别小写事件名）
   - 修正：`<div onClick={this.handleClick}>`

4. **错误4：传参时没有使用bind**
   - 错误写法：`<button onClick={this.handleClick(10)}>`
   - 后果：页面渲染即执行方法，点击无响应
   - 修正：`<button onClick={this.handleClick.bind(this, 10)}>`
