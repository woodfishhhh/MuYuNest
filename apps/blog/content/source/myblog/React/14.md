### 一、先确认运行环境和版本
#### 1. 路由包怎么选
- 浏览器端项目（99%前端场景）直接使用：`npm install react-router-dom`
- 服务端渲染（SSR）会用到：`react-router`，它提供的是平台无关的路由能力，并不只服务于浏览器 DOM
- React Native混合开发：`react-router-native`

#### 2. V5与V6不要混着查文档
| 功能点         | V5版本                  | V6版本                  |
|----------------|-------------------------|-------------------------|
| 路由容器       | `<Switch>`              | `<Routes>`              |
| 组件挂载属性   | `component={Component}` | `element={<Component />}` 或 `Component={Component}`（等价） |
| 路由跳转Hook   | `useHistory()`          | `useNavigate()`         |
| 嵌套路由占位   | 无内置组件              | `<Outlet>`              |
| 查询参数Hook   | 无内置Hook，需解析location | `useSearchParams()`     |

### 二、先决定 URL 由谁管理
#### 1. 两种路由模式
- **History模式**：
  引入 `<BrowserRouter>` 后，URL无`#`。部署时要让后端把前端路由 fallback 到入口文件，否则刷新404
  示例：`http://localhost:3000/config1`
- **哈希模式**：
  引入 `<HashRouter>` 后，URL含`#`，路由片段不会作为服务端路径发送，因此通常不需要额外配置 fallback
  示例：`http://localhost:3000/#/config1`

#### 2. Router 放在哪一层
大多数项目会在入口处包住整个应用。局部 Router 只适合目标子树外部还没有其他 Router 的情况，不能把两个 Router 随意嵌套。

```jsx
// 全局使用路由（常用）
import { BrowserRouter as Router } from 'react-router-dom';
ReactDOM.render(
  <Router>
    <App /> {/* 根组件 */}
  </Router>,
  document.getElementById('root')
);

// 局部使用路由（特殊场景）
function App() {
  return (
    <div>
      {/* 仅SubComponent1使用路由 */}
      <Router>
        <SubComponent1 />
      </Router>
      <SubComponent2 /> {/* 无路由功能 */}
    </div>
  );
}
```

### 三、把路径映射到组件
#### 1. 两个组件各管一件事
- `<Routes>` 的作用接近Vue的`<router-view>`，它会从子级`<Route>`中计算当前 location 的最佳匹配
- `<Route>` 描述一条路由规则，声明式配置时放在`<Routes>`内

#### 2. 一个最小配置
```jsx
import { Routes, Route } from 'react-router-dom';
import Config1 from './Config1';
import Config2 from './Config2';

function App() {
  return (
    <Routes>
      {/* 两种组件挂载方式（等价） */}
      <Route path="/config1" element={<Config1 />} />
      <Route path="/config2" Component={Config2} />
      {/* 404路由（path="*"匹配所有未定义路径） */}
      <Route path="*" element={<NotFound />} />
    </Routes>
  );
}
```

### 四、页面里的链接怎么选
#### 1. `<NavLink>`：需要匹配态的导航
这一版可以通过回调拿到匹配状态，再决定 className 或 style。下面第二个示例直接根据 isActive 设置颜色；第一个固定使用`active`类，需要样式或回调逻辑自行配合。

```jsx
import { NavLink } from 'react-router-dom';
// 选中时文字变红（通过active类控制）
<NavLink to="/config1" className="nav-link">配置1</NavLink>
// 自定义激活样式
<NavLink to="/config2" style={({isActive}) => ({color: isActive ? 'red' : 'black'})}>配置2</NavLink>
```

#### 2. `<Link>`：只负责跳转
不需要匹配态时用它即可。它的行为类似`<a>`标签，但由前端路由接管，不会进行整页刷新：`<Link to="/config3">跳转到配置3</Link>`

### 五、重定向和嵌套路由
#### 1. `<Navigate>`（路由重定向）
当渲染条件不满足时，可以返回它做声明式重定向：
```jsx
import { Navigate } from 'react-router-dom';
// 声明式：未登录时重定向到登录页
<Route path="/profile" element={localStorage.getItem('token') ? <Profile /> : <Navigate to="/login" />} />
```

#### 2. `<Outlet>`（嵌套路由占位）
父路由组件需要明确告诉子路由渲染到哪里，Outlet 就是这个占位位置，作用接近Vue的`<router-view>`。

```jsx
// 父组件 Config2.jsx
import { Outlet } from 'react-router-dom';
function Config2() {
  return (
    <div>
      <h1>配置2</h1>
      <Outlet /> {/* 子路由内容渲染此处 */}
    </div>
  );
}

// 路由配置
<Route path="/config2" element={<Config2 />}>
  <Route path="sub1" element={<Config2Sub1 />} /> {/* 匹配 /config2/sub1 */}
  <Route path="sub2" element={<Config2Sub2 />} /> {/* 匹配 /config2/sub2 */}
</Route>
```

### 六、从 URL 里取参数
#### 1. 动态路由定义（路径参数）
在路径中用 `path="/config3/:id"` 声明动态段，`:`后面的内容是参数名：
```jsx
<Route path="/config3/:id" element={<Config3 />} />
// 匹配路径：/config3/123、/config3/456 等
```

#### 2. 3种参数来源对应三个Hook
##### （1）路径参数（params）：`useParams()`
路径参数来自动态路由片段：
```jsx
import { useParams } from 'react-router-dom';
function Config3() {
  const { id } = useParams(); // 解构获取id，类型为字符串
  return <h1>配置3的ID：{id}</h1>;
}
```

##### （2）查询参数（query）：`useSearchParams()`
查询参数位于URL的`?`后面，例如`?a=1&b=2`：
```jsx
import { useSearchParams } from 'react-router-dom';
function Config4() {
  const [searchParams, setSearchParams] = useSearchParams();
  // 获取参数：searchParams.get(参数名)
  const a = searchParams.get('a'); // 读取a的值
  // 设置参数：setSearchParams({key: value})
  const handleSetParams = () => setSearchParams({ a: 888, b: 666 });
  return (
    <div>
      <p>查询参数a：{a}</p>
      <button onClick={handleSetParams}>修改参数</button>
    </div>
  );
}
```

##### （3）路径信息：`useLocation()`
如果不只需要某个参数，而是要读取路径、查询字符串或 state，可以取完整 location：
```jsx
import { useLocation } from 'react-router-dom';
function Config1() {
  const location = useLocation();
  console.log(location);
  /* 输出结构：
  {
    pathname: "/config1", // 路径
    search: "?a=1&b=2",   // 查询参数字符串
    hash: "",             // 哈希值
    state: {},            // 路由跳转时传递的状态（不显示在URL）
    key: "x123y456"       // 唯一标识
  }
  */
  return <h1>当前路径：{location.pathname}</h1>;
}
```

### 七、编程式路由跳转：`useNavigate()`
事件处理函数里需要跳转时，使用它替代V5的`useHistory()`：
```jsx
import { useNavigate } from 'react-router-dom';
function Config2() {
  const navigate = useNavigate();
  // 基础跳转：navigate(路径)
  const goToConfig1 = () => navigate('/config1');
  // 带查询参数跳转
  const goToConfig4 = () => navigate('/config4?a=123&b=456');
  // 带状态跳转（state不显示在URL）
  const goToConfig3 = () => navigate('/config3/789', { state: { name: '配置3' } });
  // 后退/前进：navigate(数字)（-1=后退1步，1=前进1步）
  const goBack = () => navigate(-1);

  return (
    <div>
      <button onClick={goToConfig1}>跳转到配置1</button>
      <button onClick={goBack}>后退</button>
    </div>
  );
}
```

### 八、把权限判断和懒加载接进路由
#### 1. 基础权限控制有两种思路
##### 思路1：重定向（未授权跳转）
```jsx
<Route
  path="/profile"
  element={localStorage.getItem('token') ? <Profile /> : <Navigate to="/login" />}
/>
```

##### 思路2：隐藏路由（未授权不生成路由）
```jsx
{localStorage.getItem('token') && (
  <Route path="/profile" element={<Profile />} />
)}
```

#### 2. 异步路由（懒加载）
组件不必在首屏一次性加载。下面用 `React.lazy()` 拆分组件，再用 `<Suspense>` 提供加载期间的内容：
```jsx
import { lazy, Suspense } from 'react';
import { Routes, Route } from 'react-router-dom';
// 懒加载组件（替代直接import）
const LazyConfig4 = lazy(() => import('./Config4'));

function App() {
  return (
    <Routes>
      <Route
        path="/config4"
        element={
          // Suspense：指定加载时的过渡内容
          <Suspense fallback={<h2>加载中...</h2>}>
            <LazyConfig4 />
          </Suspense>
        }
      />
    </Routes>
  );
}
```
这个示例把 `<Suspense>` 放进`<Route>`的`element`。也可以在更高层统一设置 Suspense 边界；但声明式写法中，`<Routes>`的直接子项仍应是`<Route>`。

### 九、最后检查这几处
1. 路由组件层级：`<Routes>`仅能直接包含`<Route>`，`<Route>`的`element`可嵌套任意组件
2. 组件挂载：`element`需传入组件实例（`<Component />`），`Component`需传入组件本身（`Component`）
3. 版本兼容：项目中需统一使用V5或V6，不可混合使用（API不兼容）
4. 动态路由参数：`useParams()`返回值均为字符串，需手动转换类型（如`Number(id)`）
