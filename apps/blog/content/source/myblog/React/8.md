## 一、先把两种基础写法用对
### 1. className 类名样式
- JSX 里要用 `className`，不能直接写原生 `class`
- 样式仍然写在独立 CSS 文件里，组件引入后再把类名交给 className
- className 接收**字符串**，多个类名之间用空格分隔
```jsx
import './index.css'
function Demo() {
  return <div className="box active">内容</div>
}
```

### 2. style 内联样式
- 写法是**双花括号 `{{}}` + JS 对象**
- CSS 中带连字符的属性要改成小驼峰，例如 `font-size` → `fontSize`
- 数值可以省略单位，字符串则要加引号
```jsx
// 标准写法
<div style={{ color: 'red', fontSize: 20, marginTop: 10 }}>文本</div>
```

---

## 二、普通 CSS 为什么会串样式
普通 CSS 文件处在**全局作用域**。不同组件只要用了同一个类名，后加载的样式就可能覆盖前面的样式。

### 用 CSS Modules 隔离类名
1. 样式文件按 `xxx.module.css` 命名
2. 引入后会得到一个对象，通过对象属性读取类名
3. 构建时会生成唯一类名，让组件之间的样式互不覆盖

```jsx
// 引入样式模块
import styles from './Demo.module.css'

function Demo() {
  // 调用方式：styles.类名
  return <div className={styles.box}>组件内容</div>
}
```

## 三、动态样式控制
### 1. 基础方案：字符串拼接
条件不多时，直接拼接类名字符串就够用：
```jsx
const isActive = true
// 三元表达式拼接
<div className={`base-box ${isActive ? 'active' : ''}`}>
```

### 2. 条件变多时用 classnames
- classnames 可以接收对象或数组，把动态类名的判断收在一起
- 安装命令是 `npm i classnames`
- 基础写法如下：
```jsx
import classNames from 'classnames'

const cls = classNames({
  box: true, // 固定类名
  active: isActive, // 条件类名
  disabled: false
})
// 最终生成："box active"
<div className={cls}>
```

### 3. classnames + CSS Modules 结合使用
```jsx
import classNames from 'classnames/bind'
import styles from './Demo.module.css'

const cx = classNames.bind(styles)
// 自动匹配模块化类名
<div className={cx('box', { active: isActive })}>
```

---

## 四、怎么选写法
1. **基础样式**
   - 类名：`className` 接收字符串
   - 内联：`style={{ 属性名: 值 }}`，小驼峰命名
2. **样式隔离**
   - CSS Modules：文件命名 `.module.css`，通过对象调用
3. **动态样式**
   - 简单场景：模板字符串拼接
   - 复杂场景：`classnames` 库，条件控制类名
4. **组合使用**
   - 业务开发中，可以把 **CSS Modules + classnames** 放在一起使用


上面是查用法时够用的版本。下面把 **classnames + CSS Modules** 拆开看，重点解释两者为什么要通过 bind 连接。

## 一、先看两者各自负责什么
## 1. CSS Modules 负责隔离类名
它会**防止类名冲突**，让样式只作用于当前组件。使用时注意两点：
- 样式文件叫 `A.module.css`
- 引入后得到一个**对象**
```js
import styles from './A.module.css'
```
- 类名不能直接写字符串，要从这个对象上读取：
```js
styles.box
styles.active
```
原因是 CSS Modules 会把原类名编译成唯一值：
$$ \text{box} \rightarrow \text{组件名\_box\_哈希值} $$

---

## 2. classnames 负责拼接动态类名
它把**动态拼接类名**这件事封装起来，省掉复杂的模板字符串。

普通写法是：
```js
className={classNames({
  box: true,
  active: isActive
})}
```
条件计算完成后会生成：`"box active"`

---

## 二、为什么两者不能直接混用
先看一种 **错误写法**：
```js
// ❌ 错误
className={classNames({
  box: true,
  active: isActive
})}
```
CSS Modules 里的类名不是 `box`，而是 `styles.box`。

直接调用 classnames 只会生成**普通字符串**，不会把它映射成模块化类名。

---

## 三、用 classnames/bind 连接两者
## 1. 引入绑定版本
```js
import cx from 'classnames/bind'
```

## 2. 绑定 CSS Modules 对象
```js
const cls = cx.bind(styles)
```

## 3. 按普通类名字符串调用
```js
className={cls('box', { active: isActive })}
```

---

## 四、把代码放到一起
## 1. Box.module.css
```css
.box {
  width: 200px;
  height: 200px;
  background: pink;
}
.active {
  background: red;
}
```

## 2. 组件 JSX
```jsx
import styles from './Box.module.css'
import cx from 'classnames/bind'

// 关键：绑定 styles 对象
const cls = cx.bind(styles)

export default function Box() {
  const isActive = true

  return (
    <div
      // 直接写类名！不用写 styles.xxx
      className={cls('box', { active: isActive })}
    />
  )
}
```

---

## 五、bind 实际做了什么
$$ \text{cls(类名)} = \text{自动变成 styles[类名]} $$

- `cls('box')` → `styles.box`
- `cls('active')` → `styles.active`
- `cls('box', {active:true})` → `styles.box + styles.active`

也就是说，它会自动把普通类名映射成模块化类名。

---

## 六、三种写法放在一起对比
## 1. 不用 classnames
```js
className={`${styles.box} ${isActive ? styles.active : ''}`}
```

## 2. 不用 bind，映射会失效
```js
className={classNames('box', { active: isActive })}
```

## 3. 用 bind 连接 classnames 和 CSS Modules
```js
className={cls('box', { active: isActive })}
```

---

## 七、最后理一下关系
1. **CSS Modules** 会把类名变成 `styles.xxx`
2. **classnames** 负责处理字符串
3. **classnames/bind** 负责把字符串映射到模块化类名
4. 实际使用就是固定三步：
   ```js
   import cx from 'classnames/bind'
   const cls = cx.bind(styles)
   className={cls(类名, {动态类名})}
   ```
