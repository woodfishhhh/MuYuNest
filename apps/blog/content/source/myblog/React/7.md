### 一、Props 到底接收什么
1. 组件标签上的属性（如 `name="xxx"`）和标签里的子节点（HTML/组件），最后都会进入 props。组件通信和插槽都从这里开始。
2. **它和 Vue props 的处理方式不同**：
   - Vue 中，属性要先显式定义 `props` 才会被识别，子节点则交给 `<slot>` 单独处理；
   - React 中可以理解为「万物皆 props」，不需要先声明。属性、子节点、方法等传给组件的内容都由 props 承载。
3. 因此，父子传值、子父传值、兄弟传值和插槽看起来不同，实际都绕不开 props。

### 二、类组件怎么接收 Props
#### 1. 两种接收方式
- 写了构造函数时，props 会作为第一个参数传入，还要继续传给父类构造函数：
  ```javascript
  class Son extends React.Component {
    constructor(props) {
      super(props); // 必须传递 props 给父类
      console.log(props); // 访问 props
    }
  }
  ```
- 不写构造函数时，直接通过 `this.props` 访问，React 会自动挂载：
  ```javascript
  class Son extends React.Component {
    render() {
      return <div>{this.props.message}</div>;
    }
  }
  ```
#### 2. 子节点怎么处理
组件标签里的子节点会被封装为 `props.children`（React Element 对象）。先看代码：
```javascript
// 父组件使用子组件时传入子节点
<Son>我是子节点</Son>

// 子组件中访问子节点
render() {
  return <div>{this.props.children}</div>; // 渲染 "我是子节点"
}
```

### 三、给 Props 加类型验证
#### 1. 自己编写验证逻辑
验证规则写在组件的静态属性 `propTypes` 上。这里没有现成类型，需要自己判断：
```javascript
class Son extends React.Component {
  // 静态属性：类型验证规则
  static propTypes = {
    message: (props) => { // 验证 message 属性
      if (typeof props.message !== 'string') {
        console.warn('警告：message 必须是字符串类型');
      }
    }
  };

  render() {
    return <div>{this.props.message}</div>;
  }
}
```
#### 2. 用 `prop-types` 少写重复判断
这个库由 React 官方抽离出来，常见类型已经内置，不用每次手写判断：
- 安装：`npm install prop-types`
- 使用：
  ```javascript
  import PropTypes from 'prop-types';

  class Son extends React.Component {
    static propTypes = {
      message: PropTypes.string, // 验证为字符串类型
      age: PropTypes.number.isRequired, // 必传的数字类型
      list: PropTypes.arrayOf(PropTypes.object) // 对象数组类型
    };
  }
  ```
- 常用方法包括 `PropTypes.string`（字符串）、`PropTypes.number`（数字）、`PropTypes.bool`（布尔）、`PropTypes.func`（函数）、`PropTypes.arrayOf(类型)`（指定类型数组）、`PropTypes.shape({})`（指定结构对象）。

### 四、Props 默认值
默认值写在静态属性 `defaultProps` 上。父组件没有传递对应 props 时，React 才会使用它：
```javascript
class Son extends React.Component {
  // 静态属性：默认值配置
  static defaultProps = {
    message: '我是默认值' // 未传 message 时使用该值
  };

  render() {
    return <div>{this.props.message}</div>;
  }
}

// 父组件未传 message，将渲染 "我是默认值"
<Son />
```

### 五、组件间传值
#### 1. 父组件把数据传给子组件
- 父组件在子组件标签上添加属性，字符串、数字、对象和函数都可以传；
- 子组件再通过 `this.props` 读取。
- 代码如下：
  ```javascript
  // 父组件
  class App extends React.Component {
    state = { parentMsg: '来自父组件的消息' };
    render() {
      return <Son message={this.state.parentMsg} />; // 传递数据
    }
  }

  // 子组件
  class Son extends React.Component {
    render() {
      return <div>{this.props.message}</div>; // 接收并渲染
    }
  }
  ```

#### 2. 子组件把数据传回父组件
props 是只读的，子组件不能直接改父组件的数据。通常由父组件传入一个修改函数，子组件调用时把数据作为参数带回去：
- 父组件先定义修改自身状态的函数，再把函数传给子组件；
- 子组件调用这个函数，并传入要交给父组件的数据；
- 这里要留意 `this` 的指向，否则函数内 `this` 会是 `undefined`。
- 代码连起来是这样：
  ```javascript
  // 父组件
  class App extends React.Component {
    state = { parentMsg: '初始消息' };

    // 修改状态的函数（将被传递给子组件）
    changeMsg = (newMsg) => {
      this.setState({ parentMsg: newMsg });
    };

    render() {
      // 传递函数给子组件，绑定 this（箭头函数已绑定，无需额外处理）
      return <Son changeParentMsg={this.changeMsg} />;
    }
  }

  // 子组件
  class Son extends React.Component {
    render() {
      return (
        <button onClick={() => {
          // 调用父组件传递的函数，传入子组件数据
          this.props.changeParentMsg('来自子组件的消息');
        }}>
          给父组件传值
        </button>
      );
    }
  }
  ```

#### 3. 兄弟组件通过父组件中转
兄弟组件之间没有直接传值方式，需要让父组件做一次中转：
1. 兄弟 A 组件 → 父组件：通过「子父传值」将数据传给父组件；
2. 父组件 → 兄弟 B 组件：通过「父子传值」将数据从父组件传给 B 组件。
- 整个流程是：
  ```
  兄弟A → 调用父组件函数传值 → 父组件接收并更新状态 → 父组件将状态传给兄弟B → 兄弟B通过props接收
  ```

### 六、在 React 里实现插槽效果
React 没有原生 `<slot>` 标签，做法是通过 `props` 传递 React Element 或函数，也就是「将需要插入的内容作为 props 传递给子组件」。

#### 1. 匿名插槽（对应 Vue 匿名 `<slot>`）
直接把内容写成子节点，子组件通过 `props.children` 渲染：
```javascript
// 父组件（传递插槽内容）
<Son>
  <div>我是匿名插槽内容</div>
</Son>

// 子组件（渲染插槽内容）
class Son extends React.Component {
  render() {
    return (
      <div>
        <h3>子组件标题</h3>
        {this.props.children} {/* 渲染插槽内容 */}
      </div>
    );
  }
}
```

#### 2. 具名插槽（对应 Vue 具名 `<slot name="xxx">`）
把多个 React Element 放进不同的 props，子组件按名称渲染：
```javascript
// 父组件（传递多个具名插槽）
<Son
  slot1={<div>具名插槽1</div>}
  slot2={<div>具名插槽2</div>}
/>

// 子组件（按名称渲染）
class Son extends React.Component {
  render() {
    return (
      <div>
        <div>插槽1位置：{this.props.slot1}</div>
        <div>插槽2位置：{this.props.slot2}</div>
      </div>
    );
  }
}
```

#### 3. 作用域插槽（对应 Vue `<slot scope="xxx">`）
父组件传入一个「接收参数的函数」，子组件调用它时带上自身数据，这样插槽就能拿到子组件的数据：
```javascript
// 父组件（传递函数形式的插槽，接收子组件数据）
<Son
  scopeSlot={(sonData) => (
    <div>作用域插槽：{sonData}</div> // 渲染子组件传递的数据
  )}
/>

// 子组件（调用函数并传入自身数据）
class Son extends React.Component {
  state = { sonMsg: '子组件内部数据' };

  render() {
    // 调用父组件传递的函数，传入子组件数据
    const slotContent = this.props.scopeSlot(this.state.sonMsg);
    return <div>{slotContent}</div>;
  }
}
```
