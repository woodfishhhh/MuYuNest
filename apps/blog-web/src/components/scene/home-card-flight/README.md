# Home 拾光

与 Home 共用 Three.js renderer。保留原夜空 / 白天背景；中心几何体是夜间超立方体、日间莫比乌斯带。拾光中几何体不响应点击沉浸，漫游中保持原交互。

卡片由 `src/content/home-cards.json` 驱动，维护方法见 `src/content/HOME-CARDS.md`；支持诗文纸卡、图片相框和长诗分页。`/playground/home-cards` 使用相同画布渲染器预览全部内容。

`motion.ts` 保留已确认的 2.5 倍飞行速度、v2 弹簧和 0.135 拖拽角增益。文字卡与图片卡交替出现，各自按 JSON 列表顺序循环，播完一轮才重复；每隔随机 3～6 次内容掉落插入一颗四角立体星星，合计最多两个活动物体。仅按需解码图片、生成活动卡片的 CanvasTexture；图片离场后释放解码图像、纹理和几何体。失效图片单独跳过。只释放模块自己创建的材质、几何体与纹理，不释放共享 renderer。

首页与实验室复用 `src/composables/star-motion.ts`，将 22% 的原有星点排列为 19 条光束。`home-star-motion.ts` 在进入时捕获原星空，退出约 0.8 秒后交还原有星点，保留漫游和沉浸穿梭。仍由原来的单个 Points 绘制；减少动态效果偏好下使用静态排列。

桌面默认拾光，手机默认漫游，两端右下角可切换。会话中手动选择优先于窗口宽度。

首页光束参数在 `src/content/home-stars.json`：19 条、每条 10 簇、宽度 4、聚簇 1、弯曲 1、流速 0.2、视差 1.55、星点大小 1.5、延伸 1.4、角度 1°，种子 716。实验室导出的 `settings` 可直接替换该文件同名字段；实验室的主题、几何体与卡片开关不覆盖首页。

卡片背面不设独立背板，从背后可看见镜像的正面内容；两面共用纹理和消散遮罩。卡片正面、侧边和相框跟随网站主题。夜间使用炭黑纸面与浅灰文字，照片显示时轻微压暗；白天使用柔和浅色纸面。切换时只重绘活动卡片的纹理，保留位置、飞行和拖拽状态。
