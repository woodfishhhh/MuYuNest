# blog-web

Pure Vue SPA migration, parallel to `apps/blog`. Preserve Home film scroll reversal, chapter-driven scene, route names, aliases and the single mounted HomeView. Mobile adaptation is deferred by the user.

Use pnpm from the monorepo root. Generated content is never manually edited or committed. During migration static assets still originate in the legacy content pipeline; do not delete the legacy app or content source before the plan's cutover gates.
