# Blog GSAP 动效验收

日期：2026-10-18。分支：codex/blog-docs。仅本地预览，未部署线上。

## 已实现

- 外部页面进入文档：原页面 160ms 轻退，导航与 Logo 保持在原位；导航指示线通过 Flip 连续移动。
- 首次文档入场：侧栏带轻微透视和回弹进入，边缘光线、搜索、主题条目错峰出现；标题遮罩揭幕、首屏卡片依次入场、右侧目录最后展开。主要时间线约 0.9 秒。
- 文档内部跳转：保留目录展开状态及侧栏滚动位置，使用约 0.3–0.4 秒的内容过渡；当前文章高亮标记连续移动。
- 搜索/排序/主题切换：用 Flip 重排可见条目，新条目淡入。屏幕外长列表不参与逐项入场。
- 目录展开与收起：GSAP 控制高度与条目错峰，支持快速反向操作。手机目录先完成折叠再定位文章标题。
- 移动端：原生 dialog 保留焦点管理，GSAP 控制抽屉回弹、遮罩与内部条目；Escape 关闭并归还焦点。
- 移除重复的 CSS 入场和抽屉动画；GSAP 运动期间暂停卡片 hover transform 过渡，避免两个动画系统争抢。
- 中断与卸载清理 timeline/context；减少动画模式跳过位移；慢加载时继续显示加载提示。

## 验证

- 18 项受影响单元测试通过。
- 13 项原有浏览器回归通过：导航、三种屏宽和明暗模式、公式锚点、复制、文章链接与状态页。
- 4 项新增动效浏览器测试通过：完整入场/中断、搜索排序/文章往返、手机反向开合/减少动画、慢数据加载。
- 最后消除 CSS hover 与 GSAP transform 冲突后重新构建，并重跑入场测试通过。
- pnpm typecheck、pnpm build、git diff --check 通过。
