# 2026-10-18 博客整合发布验证

## 根因及修复

- 幼圆仅有 400 字重。通过浏览器逐字字体查询确认中文均来自 YouYuan、颜色一致；隔离渲染实验复现浏览器合成粗体使“可”“与”等字符发灰。禁用字重合成，以统一轻描边保留标题和目录的强调效果；Consolas 的真实粗体不受影响。
- 旧高亮使用 offsetTop/offsetLeft，而 GSAP 变换会改变 offsetParent，导致坐标混用。现在使用条目与目录根节点的矩形差值，并在动画完成后重新测量。
- DocsLayout 原本分别挂在目录页、文章页内，每次文章路由切换都会重建背景和左栏。现提升到持续存在的路由外壳，页面通过带所有权的上下文同步内容状态；切换时只过渡正文。
- 合入 PR #58 的 Three.js 几何停靠。文档背景从导航下方开始绘制，导航不遮挡停靠图形；文章直接访问也使用 Blog 场景状态。
